# DevWeb — Freelance Cleaners Portal

A MERN-stack marketplace connecting clients with freelance cleaners.
Features: scheduling, bidding, escrow payments, chat, two-way ratings.

## Stack
- Frontend: React + Vite, Tailwind, axios, react-router
- Backend: Node + Express, Mongoose
- DB: MongoDB
- Realtime: Socket.io
- Payments: Stripe Connect

## Structure
/frontend  React app
/backend   Express API

## Status
P0 — Setup (in progress)

## Setup
1. `cp .env.example .env` and fill values
2. `cd backend && npm install && npm run dev`
3. `cd frontend && npm install && npm run dev`
