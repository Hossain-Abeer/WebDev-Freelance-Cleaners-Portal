3. Framework Overview
Client (React + Vite): pages, components, routing, state/context, API client (axios), Socket client, styling (Tailwind).

Server (Express/Node): routes → controllers → services → models; middleware (auth, error, validation, logger).

DB (MongoDB): collections: users, tasks, bids, bookings, payments, reviews, messages.

Services: Socket.io gateway (chat, notifications), Stripe Connect (escrow).

Infra: Git/GitHub, .env, Docker (optional), Vercel (client) + Render/Railway (server) + MongoDB Atlas.

Repo layout:
```
/client   → React app
/server   → Express API
```


4.1 Workflow Sequence (people interacting)
1. Client registers → profile.
2. Client posts task (date, location, budget).
3. Cleaners browse → submit bids.
4. Client accepts bid → booking created.
5. Client pays → funds held in escrow.
6. Chat opens for coordination.
7. Cleaner completes → client confirms.
8. Escrow releases funds.
9. Both rate each other.
10. Reviews update profiles.



4.2 Workflow Sequence – Technical Components
1. React client → POST /auth/register → Express route → auth controller → bcrypt hash → User model → MongoDB.
2. Client → POST /tasks (JWT) → auth middleware → task controller → Task model → MongoDB.
3. Cleaner client → POST /tasks/:id/bids → bid controller → Bid model → MongoDB.
4. Client → PATCH /bids/:id/accept → bid service → creates Booking → emits Socket event → cleaner client notified.
5. Client → POST /payments/intent → Stripe service → Stripe API → webhook → Payment model → MongoDB.
6. Booking confirmed → Socket.io room created → messages persisted via Message model.
7. Client → PATCH /bookings/:id/complete → payment service → Stripe transfer → escrow released.
8. Both clients → POST /reviews → Review model → aggregate recalculated on User.

React client re-fetches profile via axios → updated ratings rendered.




5. Software Installation – Phase by Phase

P0 Setup
- Node.js LTS, npm.
- Git, GitHub account, repo init.
- VS Code + extensions (ESLint, Prettier, MongoDB, Tailwind).
- MongoDB Atlas account (or local MongoDB).
- Postman/Thunder Client.
- Client: `npm create vite@latest client -- --template react`; install `react-router-dom`, `axios`, Tailwind CSS, ESLint, Prettier. Optional state: `zustand` or Redux Toolkit.
- Server: `npm init`; install `express`, `mongoose`, `cors`, `dotenv`.
- Root: `.env`, `.gitignore`, optional `concurrently` for running both.
