Title: DevWeb – Freelance Cleaners Portal  
Type: MERN marketplace. Solo-built. Commercial MVP + portfolio project.

Overview:  
Connect clients with freelance cleaners. Clients post jobs; cleaners bid. Platform handles scheduling, escrow payments, ratings, chat.

Features:

1. Accounts & Profiles  
   - Client and cleaner registration/login.  
   - JWT auth, bcrypt, role-based access.  
   - Profiles: services, rates, availability, service area, verification.

2. Web-Based Scheduling  
   - Calendar view.  
   - Booking slots, recurring jobs, reschedule/cancel.  
   - Status: pending, confirmed, in-progress, completed.

3. Object-Oriented Task Assignment  
   - `Task` domain model with properties, methods, state transitions.  
   - Workflow: posted → bidding → assigned → completed.  
   - Cleaners assigned via accepted bid.

4. Client Offers & Cleaner Bidding  
   - Client posts job: date, location, scope, budget.  
   - Cleaners submit bids.  
   - Client accepts/rejects. Notifications sent.

5. Payment Holding & Release  
   - Escrow via Stripe Connect.  
   - Funds held on booking.  
   - Released on completion.  
   - Refund/dispute path.

6. Two-Way Ratings  
   - Client rates cleaner; cleaner rates client.  
   - Stars + comments.  
   - Aggregate scores build trust.

7. Chats  
   - Real-time via Socket.io.  
   - Per booking thread.  
   - History, read status, attachments optional.

Tech: MongoDB, Express, React, Node, Socket.io, JWT, Stripe, Git/GitHub.  
Deliverables: Source code, docs, deployed MVP.  
Outcome: Portfolio-ready, commercial test, learn-on-go.
